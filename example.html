	<`div class="description">
		<`p>
		Tagudashi is a lightweight JavaScript library that makes it easy to 
		display HTML code within a webpage. It uses backticks to escape HTML tags 
		then re-renders them on the webpage with syntax highlighting. This makes 
		it an ideal tool for tutorials, documentation, or any site where you 
		want to show HTML examples clearly and safely.
		<`/p>
	<`/div>

	

	<`h1>Why Tagudashi?<`/h1>

	<`p>
	Displaying HTML code on a webpage is surprisingly tricky—browsers try 
	to render the tags instead of showing them, forcing developers to manually
	escape characters or rely on bulky tools. Tagudashi solves this by turning 
	HTML into safe, readable code blocks, with syntax highlighting, so examples 
	look clean with minimal effort.
	<`/p>
