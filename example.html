	<`div class="description">
		<`p>
		Tagudashi is a lightweight JavaScript library that makes it easy to 
		display HTML code within a webpage. It automatically escapes HTML tags 
		so that code is shown as text rather than being executed, and it can 
		optionally highlight syntax such as tag names, attributes, and values. 
		This makes it ideal for tutorials, documentation, or any site where you 
		want to show HTML examples clearly and safely.
